 Project Overview

Urban Grocers is an online grocery delivery platform that allows users to order groceries and create shopping kits. Following updates to the Kit Creation and Delivery Services features, I analyzed the new requirements and tested the API to verify that the platform's functionality behaved as expected.

Testing Activities & Results

- Analyzed requirements for Kit Creation and Delivery Services.
- Designed and executed API test cases using Postman to validate positive and negative scenarios, required fields, boundary values, and HTTP responses.
- Executed 21 test cases, identifying 8 defects.
- Documented test results and reported defects in Jira.

Tools & Technologies: Postman, Jira, API Testing, Requirements Analysis, Bug Reporting.
